## 정확한 대결자 명칭 (포트폴리오용 정밀 표기)

대중용으로는 무료 스파크, 유료 오푸스로 부르고, 괄호에 정확한 명칭을 함께 적습니다. 앞으로 시리즈 고정 규칙입니다.

* A = 무료 스파크 (opencode/muse-spark-1.3-contributor-free, thinking medium, Aside 세션)
* B = 유료 오푸스 (claude opus 5 high, claude.ai 웹, Pro, R3 재측정에서 16초 추론)

채점 방식은 exact match, AI 심판 없음은 1편과 같습니다.
1회 측정, 작은 표본 파일럿이라는 점도 먼저 밝힙니다. 일반 우열 선언이 아닙니다.

## 결과표 2개

### 1차 파일럿 (R2, 2026-09-08)

| 문제지 | 무료 스파크 | 유료 오푸스 |
|---|---|---|
| 쏜다 14건 | 14/14 | 13/14, ns-01 1건 오매칭 |
| 팜로그 30건 | 30/30, 210/210 | 27/30, 204/210 |
| 블라인드 10건 | 10/10, 70/70 | 8/10, 67/70 |

유료 오푸스 실패 목록: ambiguous 관수 추측 기입, multi-parcel 수량 유지, multi-crop 수량 유지, b03 동일 유형 재발, b08 정상 날짜까지 null로 버림.

패턴 한 줄: 오푸스는 애매하면 메우려 하고, 스파크는 비우는 규칙을 지켰습니다.

단 스파크 만점에는 출제자 bias가 있습니다. 신규 10건 출제와 정답표 사전 열람이 같은 손에서 나왔습니다. 오푸스만 완전 블라인드라 스파크 점수는 상한 참고값입니다.

### 완전 블라인드 재측정 (R3, 2026-09-08)

| | 무료 스파크 | 유료 오푸스 |
|---|---|---|
| 케이스 | 17/20 | 17/20 |
| 필드 | 136/140 | 135/140 |

실패 내역까지 적습니다. 이게 비교의 핵심입니다.

* 스파크 실패: d03 작업 오기 파종→관수, d14 날짜 과잉 null, d16 환각 토마토 6kg→상추 4kg
* 오푸스 실패: d03 수량 40개 유지, d06 수량 9L 유지, d14 날짜 과잉 null
* 공통 실패 d14: 수량 0 + 정상 날짜에서 양쪽 다 날짜를 버림. 규칙은 날짜 유지. 명세가 직관에 반하는 지점입니다.

오푸스의 애매해도 수량 유지는 R2 multi-parcel, multi-crop에 이어 세 번째 재현입니다.

## 비교 해석: 점수보다 틀린 모양

* 스파크 실패는 산발적 읽기 오류형. 오기, 환각. 재시도, self-check로 줄일 여지가 있습니다.
* 오푸스 실패는 일관된 성향형. 격리 실패. 프롬프트로 교정해야 할 가능성이 큽니다.
* 팜로그 용도인 기록 무결성에서는 격리 실패가 더 치명적이라는 판단을 유지합니다. 나쁜 값을 살리고 좋은 값을 버리면 기록이 오염되기 때문입니다.
* R2의 스파크 우세는 표본, 조건 탓 가능성을 배제 못 합니다. R3 동점이 더 정직한 그림입니다.
