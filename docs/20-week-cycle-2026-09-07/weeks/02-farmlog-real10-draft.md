# Week 02 후보 · 팜로그 실문장형 10건 초안 (밭 이름 고정)

- 상태: 초안. 실측 아님. golden 아님. 측정 수치 없음.
- 작성일: 2026-09-11 KST
- 밭 이름 고정: p1 = 산성2리, p2 = 천태1리
- 허용 범위: 작물 상추·토마토·고추, 작업 관수·파종·정식·방제·수확, 단위 L·kg·g·개·포기, 날짜 YYYY-MM-DD만 인정
- 규칙: 모호하면 null. 복수 필지·작물·작업은 자동 분할 금지. 수량 0·음수·단위 없음은 수량 전체 null. 날짜는 유지.
- 주의: 현재 `farm-log/src/core.mjs`는 합성 1번 밭·2번 밭 기준. 이 10건을 harness에 넣으려면 산성2리·천태1리 정식 등록 필요.

## 01 날짜 말줄임형

- 입력: 어제 산성2리에서 상추 물 20리터 줬다
- 기대: worked_at null, parcel_id p1, crop 상추, work_type 관수, amount 20, unit L, missing [worked_at]
- 포인트: 어제는 날짜로 인정 안 함. 리터는 L로 정규화.

## 02 방제 정상형 (직불금용)

- 입력: 2026-09-07 천태1리 고추 방제 2L 했다
- 기대: 2026-09-07, p2, 고추, 방제, 2, L, missing []
- 포인트: 친환경 방제 기록 기본형. 7/7 만점형.

## 03 날짜 빠짐형

- 입력: 산성2리 토마토 땄다, 12kg 나왔다
- 기대: worked_at null, p1, 토마토, 수확, 12, kg, missing [worked_at]
- 포인트: 땄다는 수확. 날짜 추측 금지.

## 04 복수 필지형

- 입력: 2026-09-07 산성2리랑 천태1리 상추에 물 줬다
- 기대: 2026-09-07, parcel_id null, 상추, 관수, amount null, unit null, missing [parcel_id]
- 포인트: 두 필지면 수량 있어도 전체 null. R2·R3 격리 실패 계열.

## 05 복수 작물형

- 입력: 2026-09-07 산성2리 상추랑 토마토 심었다
- 기대: 2026-09-07, p1, crop null, 파종, amount null, unit null, missing [crop]
- 포인트: 심었다는 파종. 작물 둘이면 수량까지 null.

## 06 모호형

- 입력: 비 와서 아무것도 안 했다
- 기대: 전부 null, missing [worked_at, parcel_id, crop, work_type]
- 포인트: 뭐라도 채우면 실패. R2 ambiguous 계열.

## 07 수량 0형 (d14 계열)

- 입력: 2026-11-16 산성2리 상추 관수 0L, 물 안 줬다
- 기대: 2026-11-16, p1, 상추, 관수, amount null, unit null, missing []
- 포인트: 0L이어도 날짜 유지. 날짜까지 버리면 R3 공통 실패.

## 08 수확 정상형 (직불금용)

- 입력: 2026-09-08 산성2리 토마토 수확 6kg
- 기대: 2026-09-08, p1, 토마토, 수확, 6, kg, missing []
- 포인트: R4 t4 뼈대. 작물·수량·단위 동시 정답.

## 09 정식 포기형 (친환경용)

- 입력: 2026-09-09 천태1리 토마토 정식 100포기 심었다
- 기대: 2026-09-09, p2, 토마토, 정식, 100, 포기, missing []
- 포인트: 정식과 파종 구분. 포기는 포기 단위.

## 10 단위 빠짐형

- 입력: 2026-09-07 산성2리 상추 수확 10
- 기대: 2026-09-07, p1, 상추, 수확, amount null, unit null, missing []
- 포인트: 단위 없으면 숫자 있어도 수량 null. 추측 금지.
